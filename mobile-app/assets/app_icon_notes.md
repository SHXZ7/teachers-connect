# App Icon Generation

Since flutter_launcher_icons doesn't support SVG format directly, we need to create a PNG version of our app icon.

## Options:
1. Use online SVG to PNG converter
2. Use ImageMagick (if available)
3. Create PNG programmatically
4. Use a design tool

## Current SVG Design:
- 192x192 circular design
- Orange gradient background (#FF6B35 to #E55A2B)
- Enhanced book symbol with binding and pages
- Nova star with glow effect
- Knowledge rays radiating from center
- Professional educational theme

## Recommended PNG Sizes:
- 1024x1024 (master icon)
- 512x512 (Android adaptive icon)
- 192x192 (standard size)
